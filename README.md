One Wi-Fi network name, 32 characters or fewer, that lands a joke and implies a whole story: **"The WiFi Stayed, She Didn't"** (27 characters).

A breakup in one line. She walked out; the router is still blinking in the corner. He kept the Wi-Fi. The twist lands on the last two words, so a stranger scrolling a phone's network list gets the situation, the character, and the event — no stock Wi-Fi joke, no shock value.

## Run it

```sh
python3 main.py
```

Writes the name to `/output/entry.txt` (exactly the name, no trailing newline). Pure stdlib, deterministic — the same bytes on every run.
